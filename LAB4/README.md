# Personal Flask Portfolio

A personal portfolio web application created from the provided Flask starter project for the laboratory exercise.

## Features
- Shared navigation bar on all pages
- Personal profile page
- Contact page
- Responsive CSS and JavaScript UI
- String-to-uppercase programming work
- Area of a circle calculator
- Area of a triangle calculator
- Link-list UI

## Run locally

```bash
pip install -r requirements.txt
python app.py
```

Then open `http://127.0.0.1:5000/`.

## Before submitting

Edit the `PROFILE` and `LINKS` dictionaries in `app.py` with your own information and links. Also change the `YN` initials in the profile/avatar sections of the HTML if needed.
